☁️ 기기 간 동기화 설정

Firebase Realtime Database를 연결하면 PC·모바일·iOS·Android 어디서나 같은 데이터를 사용할 수 있어요.
아래 3가지 값을 Firebase 콘솔에서 복사해 입력하세요.

📖 설정 방법 보기
1. Firebase 콘솔 → 프로젝트 추가 (무료)
2. Realtime Database → 데이터베이스 만들기 → 테스트 모드
3. 프로젝트 설정 → 일반 → 앱 추가(웹) → API Key, Project ID 복사
4. Realtime Database → 데이터 탭 URL 복사 (https://...firebaseio.com)
5. 커플 두 분이 같은 공유 코드를 입력하면 동기화됩니다
